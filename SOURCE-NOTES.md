# Source notes

This site was built from the supplied Facebook source pack. The public UI only uses claims that were explicit in source posts or source media.

## Used as supported facts

- Business name: The Fern Private Villas.
- Location: Barangay Dolores, Mabalacat City, Pampanga.
- The business states it has two villas in Barangay Dolores.
- Private swimming pool / exclusive use.
- Modern kitchen.
- Spacious lounge.
- Spacious bedrooms.
- Overnight stays.
- Group-size packages are available; current details must be requested directly.
- Recurring use cases in source posts: family trips, barkada getaways, birthdays/celebrations, reunions, team building/team gatherings, and weddings/related gatherings.
- Facebook messaging is an active inquiry channel.
- Email found in source pack: fidespolicarpio@thefernprivatevillas.com.

## Intentionally omitted from the public UI

- Phone number: conflicting phone numbers appear in the scraped profile data and source graphics.
- Operating hours: only a transient "Closed now" label was scraped; no stable schedule was verified.
- Current rates, discounts, and promo values: several posts contain time-sensitive promotions, so the website directs visitors to inquire for current details instead.
- Exact package capacities: source media includes group-size examples, but the site avoids presenting them as universal/current capacity rules.
- Check-in/check-out times, booking policies, cancellation terms, deposits, and availability: not reliably verified in the supplied pack.
- The scraper-generated Meta/Facebook description and unrelated Meta links: treated as scrape noise and excluded.
