# The Fern Private Villas — Landing Page

A source-grounded landing page for The Fern Private Villas in Mabalacat City, Pampanga.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.


## Production check

```bash
npm run build
npm run lint
```

## Deploy

Import the repository into Vercel. No environment variables are required for the current static landing page.

## Content note

The page was built only from supplied Facebook-page source data and downloaded media. Conflicting or insufficiently verified contact details, prices, package specifics, hours, and policies were intentionally omitted.
